## Decisions Made

- **Decision:** Use Tiago Forte's BASB methodology for knowledge management — **Rationale:** Proven system for capturing and organizing project knowledge; PARA gives clear structure, CODE provides workflow, Progressive Summarization prevents information overload — **Alternatives considered:** Simple changelog, plain TODO list (too shallow), full wiki (too heavy)
- **Decision:** Use Eisenhower + ICE for prioritization — **Rationale:** Eisenhower separates urgent/important thinking; ICE provides numerical ranking within quadrants — **Alternatives:** MoSCoW (less nuanced), simple numbered list (no framework)
- **Decision:** Store knowledge in `.knowledge/` folder at project root — **Rationale:** Colocated with code, version controlled, accessible to both human and AI — **Alternatives:** External tool (loses context), wiki (separate system)
